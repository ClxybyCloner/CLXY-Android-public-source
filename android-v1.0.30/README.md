# CLXY Android 1.0.30 source

This directory contains the Android Gradle project corresponding to CLXY 1.0.30. The project is rooted in this directory.

- Package: `com.clxy.android`
- Version name/code: `1.0.30` / `16152`
- ABI: `arm64-v8a`
- Source base: `ClxyBeta` commit `04abcd5c8d16184628e31d5a6c2bb3b8af0c7fe7`

The release adds `Open Relay settings` to the blocked sign-in card and removes the About/Open-Source Licenses entry and in-app page. License texts and legal notices remain in this directory.

No release signing key or password is included. The APK is signed separately in the restricted release pipeline.
