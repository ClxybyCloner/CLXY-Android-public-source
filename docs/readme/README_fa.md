# CLXY | Cloner Xray

CLXY یک کلاینت غیررسمی VPN برای ویندوز است. منطق اتصال و ورود حفظ می‌شود؛ برنامه به حساب Firefox و سرویس پراکسی VPN بالادستی نیاز دارد. صفحهٔ ورود را همان ارائه‌دهندهٔ حساب میزبانی می‌کند و ممکن است نشان خودش را نمایش دهد.

## ساخت نسخهٔ ویندوز

در Windows 10/11 نسخهٔ x64، Flutter پایدار، Go مطابق `core/go.mod`، PowerShell 7 و Inno Setup 6 را نصب کنید و از ریشهٔ پروژه اجرا کنید:

```powershell
pwsh -File scripts/build-windows.ps1
```

پوشهٔ قابل اجرا، ZIP قابل‌حمل و نصب‌کنندهٔ کاربر در `dist/` ساخته می‌شوند و نامشان با `CLXY` آغاز می‌شود. در این محیط لینوکسی هنوز فایل ویندوزی کامپایل یا اجرا نشده؛ پس این خروجی هنوز نسخهٔ آزموده‌شده نیست.

## محدودیت سرویس

پراکسی بالادستی فقط TCP و پورت‌های وب 80، 443، 8080 و 8443 را پشتیبانی می‌کند؛ برخی برنامه‌های UDP و پورت‌های دیگر کار نمی‌کنند. حساب و دسترس‌پذیری سرویس وابستگی بیرونی‌اند.
