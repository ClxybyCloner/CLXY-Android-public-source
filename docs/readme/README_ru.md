# CLXY | Cloner Xray

CLXY — неофициальный Windows VPN-клиент. Логика подключения и входа сохранена; нужны Firefox Account и внешний VPN-прокси. Страница входа размещена у поставщика учётной записи и может показывать его брендинг.

## Сборка Windows

На Windows 10/11 x64 установите Flutter stable, Go из `core/go.mod`, PowerShell 7 и Inno Setup 6, затем запустите из корня проекта:

```powershell
pwsh -File scripts/build-windows.ps1
```

Папка приложения, ZIP и пользовательский установщик появятся в `dist/`, их имена начинаются с `CLXY`. В этой Linux-среде Windows-файл ещё не собран и не запускался, поэтому это пока не проверенный релиз.
